# wallpascii — spec

## Цель и рамки v1

wallpascii делает ASCII-обои из фото и текста под разрешение экрана пользователя и сохраняет их в PNG или JPEG. Два нативных релиза: macOS 13+ на Apple Silicon и Windows 10 1809+ / 11.

- Интерфейс только на английском.
- В v1 нет: цветного ASCII, установки обоев из приложения, режимов Tile и Span, вшитых шрифтов.

## Архитектура

Одно общее ядро на C++ и две тонкие нативные оболочки. Ядро ничего не знает про GUI: на вход фото, текст и настройки, на выход готовая картинка.

| Часть | Что внутри |
|---|---|
| Ядро (C++17/20) | подготовка фото, конвертация в ASCII, раскладка текста, экспорт |
| Оболочка macOS | AppKit на Objective-C++, рендер глифов через Core Text |
| Оболочка Windows | Win32, рендер глифов через DirectWrite |
| Картинки | stb_image (загрузка), stb_image_write (PNG/JPEG) |
| Сборка | CMake; CI через GitHub Actions на мак- и винд-раннерах |

Шрифты системные, поэтому глифы рисует оболочка средствами ОС, а ядро отдаёт ей сетку символов с цветами.

## Конвейер генерации

Превью пересчитывается сразу при любой правке.

1. **Загрузка.** JPEG/PNG через stb_image, перевод в оттенки серого.
2. **Подгонка под область.** Fill, Fit, Stretch, Center. Область = весь экран или его половина в режиме «текст рядом».
3. **Коррекция.** Яркость, контраст, Invert.
4. **ASCII.** Сетка клеток по размеру глифа выбранного шрифта; средняя яркость клетки → символ из набора (тёмное → плотный, светлое → редкий). Плотность задаёт размер шрифта.
5. **Рендер и экспорт.** Символы цветом глифов на цвете фона, в полном разрешении, PNG или JPEG.

| Настройка | Варианты |
|---|---|
| Набор символов | Simple ` .:-=+*#%@`, Detailed (длинная шкала), Blocks ` ░▒▓█`, Custom |
| Цвета | фон и глифы выбирает пользователь + пара пресетов |
| Плотность | размер шрифта ASCII |

## Режимы текста

**Side by side.** Экран делится строго 50/50: в одной половине ASCII-картинка, во второй блок текста. Четыре раскладки: картинка слева, справа, сверху или снизу. У текста свой размер шрифта и выравнивание (left, center, right), цвета общие с картинкой.

**Text as image.** Картинка на весь экран набрана символами текста пользователя, который повторяется по сетке. Набор символов не используется. Решено: текст идёт подряд, тёмные клетки становятся пробелами.

## Шрифты, разрешение, вывод

| Что | macOS | Windows |
|---|---|---|
| Шрифты | SF Mono, Courier New | Consolas, Courier New |
| Разрешение | авто по экрану с учётом Retina | авто по экрану с учётом масштаба |

- Шрифты только системные, ничего не вшиваем.
- Разрешение можно вписать вручную (ширина × высота).
- Вывод: PNG или JPEG через системный диалог сохранения.
- Превью живое, в уменьшенном масштабе, с пропорциями финального файла.

## Интерфейс

Одно окно: слева панель настроек, справа живое превью, внизу Save. Макет: `docs/mockup.png`.

1. **Image**: Choose Photo, Fill / Fit / Stretch / Center, Brightness, Contrast, Invert.
2. **ASCII**: Character set (пресет + Custom), Font, Font size.
3. **Text**: Mode (Side by side / Text as image), текст, Layout (4 варианта), Alignment, Text size.
4. **Colors**: Background, Glyphs, Presets.
5. **Output**: Resolution (Auto / Custom W × H), Format (PNG / JPEG), Save.
